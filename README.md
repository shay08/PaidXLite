# PaidX Lite

PaidX Lite helps identify potential paid service opportunities in public help posts. It separates evidence from assumptions, assesses service fit, and drafts a useful public reply and a short private offer for review.

## Use

Install the plugin in a compatible Claude environment, then share a public help post and describe the skills or services you can offer. Ask Claude to use PaidX Lite. No API keys, external accounts, or additional setup are required. Web research depends on the tools available in your environment.

The plugin drafts suggestions only. It does not contact prospects or guarantee paid work. Review every draft before using it.
